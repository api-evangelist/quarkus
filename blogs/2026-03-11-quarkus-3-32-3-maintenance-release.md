Today, we released Quarkus 3.32.3, the second maintenance release for our 3.32 stream (we skipped 3.32.0). We encourage you to test it, even if you track LTS releases, as 3.32 will be the foundation for 3.33 LTS. Update To update to Quarkus 3.32, we recommend updating to the latest version of the Quarkus CLI and run: quarkus update Note that quarkus update can update your applications from any version of Quarkus (including 2.x) to Quarkus 3.32.
