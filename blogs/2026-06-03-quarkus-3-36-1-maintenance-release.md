Today, we released Quarkus 3.36.1, a maintenance release for our 3.36 release train. Users can upgrade using the quarkus update command, which supports migrations from any Quarkus version including 2.x to 3.36. The team invites community feedback through GitHub issues, pull requests, Zulip chat, mailing lists, and Stack Overflow.
