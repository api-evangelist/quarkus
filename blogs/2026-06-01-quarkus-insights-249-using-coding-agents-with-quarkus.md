In episode 249 of Quarkus Insights, Philip Kruger demonstrated how coding agents can enhance the Quarkus developer experience using the new Quarkus Agent MCP server, which bridges general-purpose coding agents into a Quarkus expert capable of creating projects, upgrading versions, and migrating entire Spring Boot applications to Quarkus. The discussion covers the Quarkus 3.36 platform release, which includes OIDC Spiffe authentication, Signals (a new eventing infrastructure), and enhanced developer experience features. Tool management, documentation integration, skill customization, and real-world development practices using various AI harnesses and models were all covered.
