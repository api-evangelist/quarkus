We are pleased to announce the release of A2A Java SDK 1.0.0.Beta1, our first release fully aligned with the final A2A Specification 1.0.0 . The A2A Protocol has reached stability as an open standard, and this release marks the Java SDK tracking that maturity: protocol conformance is the central focus, and the SDK coordinates now reflect the project’s identity under the A2A Project organization . As a sign of this maturity, two structural breaking changes accompany this release: Java packages have been renamed from io.a2a. to org.a2aproject.sdk.
