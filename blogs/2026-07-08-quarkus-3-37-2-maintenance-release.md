Today, we released Quarkus 3.37.2, a maintenance release for our 3.37 release train. Update To update to Quarkus 3.37, we recommend updating to the latest version of the Quarkus CLI and run: quarkus update Note that quarkus update can update your applications from any version of Quarkus (including 2.x) to Quarkus 3.37. For more information about the adjustments you need to make to your applications, please refer to the Quarkus 3.37 migration guide .
