Today, we released Quarkus 3.20.6, our next maintenance release for the 3.20 LTS stream. This release contains bugfixes, documentation updates and fixes the following CVEs: CVE-2026-1002 CVE-2025-33042 It should be a safe upgrade for anyone already using 3.20. Update To update to Quarkus 3.20, we recommend updating to the latest version of the Quarkus CLI and run: quarkus update --stream=3.20 Note that quarkus update can update your applications from any version of Quarkus (including 2.x) to Quarkus 3.20.
