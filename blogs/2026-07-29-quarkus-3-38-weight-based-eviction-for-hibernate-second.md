We’re pleased to announce the release of Quarkus 3.38. As most of the development effort for new features and major upgrades is now focused on Quarkus 4, this release is lighter on features than usual. It still comes with the following notable features: #55284 - Support weight-based eviction for Hibernate 2LC Caffeine cache regions Quarkus HTTP Problem added to the Platform Update To update to Quarkus 3.38, we recommend updating to the latest version of the Quarkus CLI and run: quarkus update Note that quarkus update can update your applications from any version of Quarkus (including 2.x) to Q
