We’re pleased to announce the release of Quarkus 3.32. This is an important milestone: 3.32 marks the feature freeze for our next LTS release, Quarkus 3.33 LTS. The upcoming LTS will be branched from the 3.32 line, making this release the foundation on which 3.33 LTS will be built.
