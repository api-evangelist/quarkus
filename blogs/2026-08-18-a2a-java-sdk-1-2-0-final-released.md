I am happy to announce the release of A2A Java SDK 1.2.0.Final . This release hardens the authorization model, adds stream lifecycle management, and fixes several protocol compliance issues. The A2A Java SDK is the official Java implementation of the A2A Protocol , with Quarkus as its reference runtime.
