Today, we released Quarkus 3.34.2, the first maintenance release for our 3.34 stream (we skipped 3.34.0). Update To update to Quarkus 3.34, we recommend updating to the latest version of the Quarkus CLI and run: quarkus update Note that quarkus update can update your applications from any version of Quarkus (including 2.x) to Quarkus 3.34. For more information about the adjustments you need to make to your applications, please refer to the Quarkus 3.34 migration guide .
