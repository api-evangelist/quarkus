Skills are an open standard for packaging reusable instructions that teach AI coding agents how to perform specialized tasks. The Quarkus project maintains its own collection of Skills in a dedicated repository, transforming general-purpose coding agents into Quarkus experts capable of handling complex migration tasks like converting Spring Boot applications to Quarkus. The modular migration approach includes domain-specific modules for build configuration, code conversion, frontend migration, testing updates, and cleanup, with gate checks to ensure builds remain functional.
