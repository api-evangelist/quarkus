Goodbye Hibernate with Panache Next… welcome Quarkus Data Hibernate 🥳 It’s already been a while since we introduced Quarkus Hibernate with Panache Next , and since then, we’ve decided to move closer to the Jakarta Data standard, as well as rename the module to Quarkus Data Hibernate . I’ll repeat the original disclaimer: this is a new extension, which is experimental, which means everything about it can (and probably will) change: the extension name, the package names, the class names and even the API.
